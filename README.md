# King — instalador para Windows

Assistente de IA na ilha dinâmica do Windows (Windows 10 e 11).

## Como instalar
1. Clique em **King Setup 1.0.2.exe** acima e depois em **Download** (botão de baixar à direita).
2. Abra o arquivo baixado. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo** (o instalador não tem assinatura digital paga).
3. Instale e abra o King. Na primeira vez ele abre um guia que leva você até as chaves grátis do **Groq** e do **Gemini**: é só seguir os passos e colar a chave. (O guia também fica no menu do ícone do King, perto do relógio, em "Pegar chaves grátis".)
